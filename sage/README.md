# SNOVA in SageMath

This directory contains the SageMath script `snova.sage`, which implements SNOVA and can generate valid KAT files. The script supports the SNOVA variant with rectangular signatures introduced in Round 3.

The directory also contains `mayo_snova.sage`, which implements an alternative representation of the SNOVA public map. It can generate valid Round 2 SNOVA KAT files as well as the Round 2 MAYO-1 KAT files. This script demonstrates that MAYO can be viewed as an instance of SNOVA with \(l=1\).

The `sagekat.py` script can be used to verify the KAT files generated by `snova.sage` for all recommended SNOVA instances.
